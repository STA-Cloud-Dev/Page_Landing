# Oracle regions snapshot

Source: https://www.oracle.com/cloud/public-cloud-regions/
Checked 2026-11-11. Commercial public regions: 45 live, Kenya and Morocco 2 coming soon. Government, Sovereign and multicloud database deployments excluded from retail VPS catalog. Vietnam and Hong Kong remain separate STA Cloud locations. Coordinates are illustrative city locations. Ping is randomized simulation, not a measured latency or SLA.

Country flag SVGs in `public/flags/oracle-*.svg` were obtained from https://flagcdn.com/ (Flagpedia) using ISO 3166-1 alpha-2 country codes.
